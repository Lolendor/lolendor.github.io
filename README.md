# Lolendor GitHub Pages

Personal project directory at https://lolendor.github.io/.

The page lists selected public repositories, grouped into browser-accessible web
projects and source-code repositories. Project links and descriptions live in
`index.html`; the layout uses the system font and `style.css`.

GitHub Pages publishes the root of `main` without Jekyll. Root-level `robots.txt`
and `sitemap.xml` help crawlers discover the public web projects, including
Compressorio.

Preview locally with `python3 -m http.server 8767`.
